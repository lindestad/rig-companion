# Launcher icons

Application logos identify their respective launch targets; rights remain with their owners. These are extracted from the user's installed application icons, not original Rig Companion artwork.

- iRacing: icon from `iRacing/ui/iRacingUI.exe`.
- Content Manager: icon from `Content Manager.exe`.
- Rally, EVO, LMU: Steam shortcut icons for app IDs 3917090, 3058630, 2399420 respectively, from Steam's `steam/games` folder.

PNG files preserve the extracted source images. The embedded `.rgba` variants are transparent 64 × 64 RGBA8 canvases with aspect-preserving resized icons.
